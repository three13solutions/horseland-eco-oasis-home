# Home Hero Carousel Multi-Image Selector

## Goal
Replace the Home Page Hero Banner's separate image rows with one multi-image selection box.

## Changes
- Reuse the existing multi-image media selector already used for room galleries.
- Let administrators select or upload multiple carousel images in one dialog.
- Display all selected images together with individual remove controls.
- Keep the selected image order and synchronize each image's stored media key when saving.
- Preserve the existing hero carousel, page data, and frontend behavior.

## Verification
- Confirm the Home Page carousel editor displays one selector rather than individual rows.
- Confirm selecting and removing multiple images updates the existing carousel data correctly.
- Confirm the preview builds without errors.
